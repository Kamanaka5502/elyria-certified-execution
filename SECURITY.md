This repository is a protected public proof surface for consequence-bearing AI execution certification. It is not a production system, certification engine, customer audit package, or runtime enforcement release.

## Public review scope

Review is limited to public-safe materials:

```text
README.md
PROTECTED_SCOPE.md
NOTICE.md
AUTHORS.md
public certification levels
public proof requirements
public visual assets
```

## Do not publish here

```text
secrets or credentials
live customer data
production endpoint details
customer certification reports
private runtime law
protected enforcement internals
private certification methods
private law bundles
production deployment architecture
NDA-bound proofs
commercial pilot terms
```

## Public issue scope

Public issues should be limited to documentation clarity, public certification-level clarity, public proof-requirement clarity, unsafe public wording, and protected-scope boundary clarity.

## Boundary

The absence of private runtime law, private certification methods, customer reports, and production deployment architecture is intentional.
